# Gestión de Proyectos Ágiles en 2026 con IA Agéntica

Presentación web interactiva sobre la evolución de la gestión ágil en la era de la IA agéntica.

## Contenido

- **`gestion-agil-2026-ia-agentica.md`** — Investigación completa con datos, frameworks y análisis
- **`prompt-claude-code-presentacion.md`** — Prompt para generar la presentación web interactiva

## Temas principales

- Fundamentos ágiles en contexto agéntico (ciclo empírico, liderazgo, equipos)
- Evolución: asistente → agente → multiagente → ecosistema
- Datos de adopción e impacto (McKinsey 2025, DORA, Microsoft WTI)
- Productividad local vs. sistémica
- Sistema ágil-agéntico end-to-end
- Gobernanza y métricas

## Stack de la presentación

React + Tailwind CSS, tema oscuro, diagramas SVG animados, quizzes interactivos.
